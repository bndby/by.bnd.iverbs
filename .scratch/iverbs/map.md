# Нативная спецификация неправильных глаголов

Type: wayfinder:map
Status: resolved

## Destination

Спецификация нативного Android-приложения для одного ученика: главная, страница глаголов, режимы Учим и Проверка. По ней следующая сессия собирает приложение без новых продуктовых вопросов.

## Notes

Домен: неправильные глаголы. Термины в `GLOSSARY.md`. Каждая сессия сверяется с ним и при необходимости вызывает grilling и domain-modeling. Research-билет ведётся навыком research.

Репозитория git нет, ветку `research/` запушить некуда. Находки research класть файлом в `.scratch/iverbs/research/` и ссылаться на него из ответа билета.

Уже решено, заново не открывать:

- Один ученик, данные на устройстве. Прогресса, учёток и других языков нет.
- Четыре поверхности: главная (Учим, Проверка, вход на страницу глаголов), страница глаголов, Учим, Проверка.
- Глагол: одно значение и три формы. Инфинитив без частицы to. Одно написание на форму.
- Из Учим и Проверки можно открыть страницу глаголов и сменить отметки. Смена видна со следующего выбора, текущий ход доигрывает свой глагол. Под страницей глаголов ход стоит; прерванная озвучка сама не стартует снова.
- Ход идёт, пока ученик не выйдет. Глагол берётся равновероятно из списка, подряд может выпасть тот же. Озвучка стартует сама и один раз. Слушание кончается концом фразы или кнопкой «Готово». Вердикт сразу после этого.
- «Дальше» есть во время слушания и после вердикта. «Ещё раз» повторяет озвучку того же глагола и снова открывает слушание: в Учим значение и три формы, в Проверке только инфинитив.
- Совпало: ровно три слова в порядке записи, без учёта регистра; пунктуация и лишние пробелы не мешают, лишнее слово не совпадает. После вердикта видны три формы записи и распознанный текст.
- Подписи русские. Значение говорит русский голос, английские формы — английский. Ответ ученика в обоих режимах английский.
- Когда не отмечен ни один глагол, с главной и по «Дальше» из Учим или Проверки открывается страница глаголов, новый ход не начинается.

## Decisions so far

- [Какая речь на Android работает без сети?](issues/02-rech-bez-seti.md): без сети платформа не обещает голос и английскую модель — они должны быть уже скачаны; встраиваемые модели это закрывают, движок не выбран.
- [Какой стартовый набор неправильных глаголов обычен?](issues/03-startovyy-nabor.md): одного обычного набора нет — British Council даёт 52, Cambridge English Grammar Today 106, Essential Grammar in Use 86, и вторые формы расходятся.
- [Какие записи глагола можно сохранить?](issues/01-sohranenie-glagola.md): ученик не меняет записи; в новом приложении отмечен весь набор, одна отметка включает глагол в список для Учим и Проверки.
- [Обязан ли ход проходить без сети?](issues/04-hod-bez-seti.md): да; русская озвучка, английская озвучка и английское распознавание вложены в приложение, движок Sherpa-ONNX.
- [Где проходит граница совпадения?](issues/05-granitsa-sovpadeniya.md): пунктуация и лишние пробелы не мешают; лишнее слово, в том числе to и артикль, не даёт «совпало».
- [Можно ли менять список, пока идёт ход?](issues/06-spisok-vo-vremya-hoda.md): да, из Учим и Проверки; пустой список на «Дальше» открывает страницу глаголов; под ней ход стоит, прерванная озвучка сама не повторяется.
- [Какой стартовый набор поставлять?](issues/07-kakoy-nabor-postavlyat.md): целиком 52 тройки British Council для beginner; у be запись be — was — been, were не совпадает.
- [Что происходит, если ход не может говорить или слушать?](issues/08-hod-ne-mozhet-govorit.md): пока слушание не началось, ученик остаётся в режиме без вердикта и видит одну из трёх причин; «Ещё раз» повторяет тот же глагол; после старта слушания ход обычный.
- [Какие русские соответствия есть у троек набора?](issues/10-russkie-sootvetstviya.md): Cambridge English–Russian даёт строку всем 52; больше одной почти у каждого, у lie «лгать» — другой глагол.
- [Какие модели Sherpa-ONNX вложить?](issues/09-modeli-sherpa.md): кандидаты на три способности есть, готовый APK несёт одну модель; комплект для приложения не выбран.
- [Какое значение записать каждому глаголу?](issues/11-znachenie-glagola.md): один инфинитив с самой ранней строки Cambridge, без «ся» в скобках; у make, say и tell уточнение через «или».
- [Какой облик у четырёх поверхностей?](issues/12-oblik-poverhnostey.md): один столбец «Крупно»; главная — три полосы, в слушании Учим формы прячутся.
- [Какой комплект моделей вложить?](issues/13-komplekt-modeley.md): сначала int8 Piper dmitri и cori medium и Moonshine Tiny. Позже вложенные модели заменены службами телефона.
- Службы телефона вместо вложенных моделей: минимальная версия Android — 12. При первом запуске приложение скачивает недостающие русский и английский голос и английскую модель распознавания. Ход говорит через `TextToSpeech` и слушает через `SpeechRecognizer`.
- Спецификация приложения: [spec.md](spec.md), статус `ready-for-agent`. Шов тестов — ход.
