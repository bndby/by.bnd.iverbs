# 17: Смена отметок посреди хода

**What to build:** Пока идёт Учим или Проверка, ученик открывает страницу глаголов и меняет отметки. Текущий ход доигрывает свой глагол. Под страницей ход стоит: озвучка не продолжается и вердикт сам не наступает. «К ходу» возвращает в ту же фазу, «Дальше» берёт глагол уже из нового списка.

**Blocked by:** 16. Страница глаголов хранит список

**Status:** resolved

- [x] Из Учим и Проверки страница глаголов открывается и во время слушания, и после вердикта. В ходе рядом с «Главная» есть «Глаголы».
- [x] Смена отметок не меняет глагол текущего хода.
- [x] Пока страница открыта, фраза останавливается и вердикт сам не наступает.
- [x] «К ходу» есть только когда ход ждёт, и возвращает в ту же фазу того же глагола.
- [x] Прерванная озвучка сама не начинается. В Учим после возврата сверху «Ход ждёт», крупно значение и три формы, снизу только «Ещё раз». В Проверке по-прежнему только инфинитив.
- [x] Возврат в слушание слушает заново, а текст, распознанный до ухода, сброшен.
- [x] «Ещё раз» повторяет глагол этого хода, даже если отметку с него сняли и даже если список опустел.
- [x] «Дальше» берёт глагол равновероятно из уже нового списка. Пустой список открывает страницу глаголов, и новый ход не начинается.
- [x] «Главная» из режима и со страницы глаголов бросает ход и оставляет три полосы.
- [x] Это проверяется через ход, включая остановку речи на время страницы глаголов.
