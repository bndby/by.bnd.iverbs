# Какое значение записать каждому глаголу?

Type: grilling
Status: resolved
Blocked by: 10

## Question

У глагола одно значение: русская строка, которой он называется ученику. [Какие русские соответствия есть у троек набора?](10-russkie-sootvetstviya.md) соберёт соответствия источников для 52 троек набора.

Какую одну русскую строку записать каждому глаголу? Если источников несколько или у глагола несколько смыслов, какое соответствие становится значением?

## Answer

Значение — строка из Cambridge English–Russian, со статьи, чьи прошедшие формы совпадают с тройкой. «лгать» у lie и «оценивать» у cost в значение не входят. Внутри статьи не берётся вспомогательный и модальный глагол и не берётся готовая фраза. Кандидат — обычное значение; оборот тоже кандидат, когда это модель основного смысла. Побеждает самый ранний уровень CEFR, при равенстве — строка выше на странице.

В значение входит один несовершенный инфинитив: без пометы, без скобок и без частицы «ся» внутри них, без «и т. д.» и без второго слова через запятую. Несколько слов бывают только там, где один инфинитив достался бы двум глаголам. Уточнение присоединяется через «или» и берётся из той же выигравшей строки.
