# 15: Проверка доходит до вердикта

**What to build:** С главной ученик входит в Проверку. Ход сам один раз говорит только инфинитив английским голосом. До вердикта на экране только инфинитив. Ученик произносит три формы, и вердикт считается так же, как в Учим. «Ещё раз» и «Дальше» остаются при этом режиме.

**Blocked by:** 14. Учим доходит до вердикта

**Status:** resolved

- [x] На главной появляется вход в Проверку, и глагол берётся равновероятно из всего набора.
- [x] Фраза Проверки — один инфинитив английским голосом, сама и один раз.
- [x] До вердикта на экране только инфинитив: ни значения, ни трёх форм, ни «Говорит», ни «Ход ждёт».
- [x] Кнопки те же по фазам, что в Учим: пока фраза звучит — только «Ещё раз»; в слушании — «Готово», «Ещё раз», «Дальше»; после вердикта — «Ещё раз» и «Дальше».
- [x] Ответ ученика английский, из трёх форм. Граница «Совпало» та же, и после вердикта видны три формы записи и распознанный текст.
- [x] «Ещё раз» снова говорит только инфинитив того же глагола. «Дальше» берёт новый глагол равновероятно.
- [x] Новое поведение проверяется через ход подставным исходом речи.
