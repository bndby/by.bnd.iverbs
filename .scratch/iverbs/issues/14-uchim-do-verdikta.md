# 14: Учим доходит до вердикта

**What to build:** С главной ученик входит в Учим. Ход сам один раз говорит значение русским голосом и три формы английским, затем слушает английский ответ. Конец фразы или «Готово» сразу ставит вердикт. «Ещё раз» повторяет тот же глагол, «Дальше» берёт следующий из всего набора. Полос «Проверка» и «Глаголы» на главной ещё нет.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] С главной ученик входит в Учим, и глагол берётся равновероятно из всего набора, в том числе тот же подряд.
- [x] Фраза начинается сама и один раз: значение русским голосом, затем три формы по порядку английским. Пауза между ними — часть той же фразы.
- [x] Пока фраза звучит, сверху мелко «Говорит», крупно значение и три формы столбиком, снизу только «Ещё раз».
- [x] В слушании остаётся только значение, формы спрятаны, снизу столбиком «Готово», «Ещё раз», «Дальше».
- [x] Конец фразы или «Готово» сразу показывает «Совпало» или «Не совпало», под ним три формы записи, ниже распознанный текст одной строкой, как его вернул слух. «Готово» исчезает, остаются «Ещё раз» и «Дальше».
- [x] «Совпало» — ровно три слова в порядке записи, без учёта регистра. Пунктуация и лишние пробелы не мешают. Лишнее слово, частица to, артикль, другой порядок, неполное число слов, другое написание и пустой текст дают «Не совпало». У be were не совпадает с was.
- [x] «Ещё раз» с начала говорит тот же глагол и снова открывает слушание. «Дальше» берёт новый глагол равновероятно.
- [x] Новый запуск открывает главную, незаконченного хода нет.
- [x] Облик «Крупно»: один столбец, бумага и тёмные чернила, основной текст с засечками, кнопки обведены, залита только «Готово».
- [x] Поведение хода проверяется снаружи подставным исходом речи: фраза кончилась, слушание кончилось с текстом.
