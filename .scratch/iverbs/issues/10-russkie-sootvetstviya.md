# Какие русские соответствия есть у троек набора?

Type: research
Status: resolved
Blocked by: 07

## Question

[Какой стартовый набор поставлять?](07-kakoy-nabor-postavlyat.md) зафиксировал набор: 52 тройки British Council для beginner. У `be` запись `be — was — been`. У `lie` запись `lie — lay — lain`.

Какие русские соответствия первичные учебные источники дают этим тройкам? Нужен источник, который сам даёт русскую строку к английскому глаголу, критерий его отбора и соответствия по каждому из 52 инфинитивов. Где смыслов несколько или источники расходятся, записать варианты, не выбирая значение для продукта. `lie — lay — lain` не смешивать с глаголом «лгать». Прозу учебника не копировать.

Находку положить в `.scratch/iverbs/research/russkie-sootvetstviya.md`. Git-репозитория нет, ветку `research/` создать нельзя.

## Answer

Один источник покрывает все 52 инфинитива: Cambridge English–Russian Dictionary. На странице словаря критерий — слова CEFR A1–B2 из English Vocabulary Profile, словарь для intermediate learners (A2–B2).

Русская строка есть у каждого инфинитива. Больше одной строки у 51 глагола. У `buy` строка одна: «покупать».

У `lie — lay — lain` строки «лежать…» и «находиться…». «лгать, обманывать» стоит у другого глагола, `lied`, и в тройку не входит. У `cost — cost — cost` строка «стоить»; «оценивать» — вторая статья того же инфинитива без прошедших форм.

Какую строку записать как значение, эта находка не выбирает. Таблицы: [russkie-sootvetstviya.md](../research/russkie-sootvetstviya.md).
