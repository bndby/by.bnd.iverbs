# 19: Ход говорит и слушает без сети

**What to build:** На устройстве Учим и Проверка сами говорят и слушают без сети и без скачивания. Русское значение говорит dmitri, английские формы и инфинитив — cori, ответ разбирает Moonshine, конец фразы ученика ловит silero. Ход доходит от озвучки до вердикта тем поведением, которое уже собрано.

**Blocked by:** 18. Ход не может начать

**Status:** ready-for-agent

- [ ] После установки ход проходит без сети и ничего не скачивает. Платформенные голос и распознавание не используются.
- [ ] Движок — Sherpa-ONNX 1.13.8, со всё ещё включённым espeak-ng и с исправлением int8, из-за которого вторая фраза не срывается.
- [ ] Русская озвучка — Piper dmitri, medium, один диктор, 22050 Гц. Английская — Piper cori, en_GB, женский голос, medium, 22050 Гц. Каталог espeak-ng-data один на обе. Файлы onnx.json в приложение не входят.
- [ ] Английское распознавание — непотоковый Moonshine Tiny English. Каталог test_wavs не входит. Конец фразы ученика определяет silero VAD.
- [ ] Вложенный комплект файлов — тот, что назван в спецификации.
- [ ] Учим произносит значение по-русски и три формы по-английски. Проверка произносит только инфинитив по-английски. «Готово» по-прежнему завершает слушание.
- [ ] Если модель режима не открылась, ход показывает «Модель не открылась» и не начинает фразу.
- [ ] Приложение публикуется под GPL-3, исходники доступны по запросу.
- [ ] Уже собранное поведение хода на подставном исходе речи остаётся зелёным. Живой движок проверяется тем, что фраза звучит и распознанный текст доходит до вердикта без сети.
