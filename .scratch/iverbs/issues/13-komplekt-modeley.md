# Какой комплект моделей вложить?

Type: grilling
Status: resolved
Blocked by: 09

## Question

[Какие модели Sherpa-ONNX вложить?](09-modeli-sherpa.md) собрал кандидатов. Готовый APK Sherpa несёт одну модель. Приложению нужны сразу три способности без сети на время хода: русская озвучка, английская озвучка, английское распознавание.

Какие файлы моделей входят в приложение? Точность на трёх коротких формах не измерена, и этот билет её не назначает.

## Answer

Три способности, три отдельных комплекта. Приложение публикуется под GPL-3, исходники доступны по запросу: готовая сборка Sherpa-ONNX с озвучкой включает espeak-ng. Библиотека — сборка, где этот код ещё внутри и где уже закрыт сбой int8 на второй фразе (исправление в 1.13.3; страницы APK в находке «Какие модели Sherpa-ONNX вложить?» — 1.13.8).

Русская озвучка — Piper dmitri, medium, один диктор, 22050 Гц. Архив `vits-piper-ru_RU-dmitri-medium-int8.tar.bz2` (20,2 МиБ). В приложение входят `ru_RU-dmitri-medium.onnx`, `tokens.txt` и `MODEL_CARD`. Датасет CC0, веса в репозитории piper-voices с лицензией MIT. Файл onnx внутри архива int8 носит то же имя, что и полный: это уменьшенные веса, не архив на 64 МиБ.

Английская озвучка — Piper cori, `en_GB`, один диктор, женский голос, medium, 22050 Гц. Архив `vits-piper-en_GB-cori-medium-int8.tar.bz2` (19,8 МиБ). В приложение входят `en_GB-cori-medium.onnx`, `tokens.txt` и `MODEL_CARD`. Датасет LibriVox, public domain. Имя onnx снова от полного архива, веса — из int8.

`espeak-ng-data` в обоих архивах совпадает пофайлово. В приложение входит один каталог. `*.onnx.json` из этих архивов движок в документированном `OfflineTts` не читает, в приложение он не входит.

Английское распознавание — непотоковый Moonshine Tiny English, архив `sherpa-onnx-moonshine-tiny-en-quantized-2026-02-27.tar.bz2`. В приложение входят `encoder_model.ort`, `decoder_model_merged.ort`, `tokens.txt` и `LICENSE`. Распакованный каталог 43 МиБ. Лицензия английских моделей Moonshine — MIT. Каталог `test_wavs` не входит.

Рядом `silero_vad.onnx` с релиза `asr-models`, 643854 байт, лицензия MIT.

Точность на трёх коротких формах не измерялась.
