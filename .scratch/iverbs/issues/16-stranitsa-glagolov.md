# 16: Страница глаголов хранит список

**What to build:** С главной ученик открывает страницу всех 52 глаголов набора и отмечает, какие входят в список. Одна отметка служит и Учим, и Проверке. Отметки остаются на устройстве. Пустой список не даёт начать ход ни с главной, ни по «Дальше».

**Blocked by:** 15. Проверка доходит до вердикта

**Status:** resolved

- [x] Главная — три равные полосы на весь экран, текст слева: Учим, Проверка, Глаголы.
- [x] Страница глаголов показывает набор в записанном порядке, одним столбцом. В строке квадрат отметки, значение и под ним мельче инфинитив. Отмеченный квадрат залит и с галкой.
- [x] В новом приложении отмечен каждый глагол. Ученик не добавляет, не удаляет и не правит глаголы: меняется только отметка.
- [x] Одна отметка включает глагол в список сразу для Учим и Проверки. Снятие убирает его из обоих и оставляет в наборе.
- [x] Отметки сохраняются между запусками. После запуска ученик на главной, незаконченного хода нет.
- [x] При пустом списке Учим и Проверка с главной открывают страницу глаголов, и ход не начинается.
- [x] Если к «Дальше» список пуст, ход не начинается и открывается страница глаголов.
- [x] Сверху «Главная». «К ходу» нет, пока никакой ход не ждёт.
- [x] Значение и три формы — те, что записаны в спецификации.
- [x] Список и пустой вход проверяются через ход.
