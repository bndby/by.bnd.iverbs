# 18: Ход не может начать

**What to build:** Если режим не может и говорить, и слушать, ученик остаётся в Учим или Проверке без вердикта и видит одну причину. «Ещё раз» повторяет тот же глагол, просит разрешение микрофона или открывает настройки. После старта слушания обрыв этими причинами не подменяется.

**Blocked by:** 17. Смена отметок посреди хода

**Status:** resolved

- [x] Фраза не начинается, пока Учим не может говорить по-русски, говорить по-английски и слушать по-английски, а Проверка — говорить по-английски и слушать по-английски.
- [x] Ученик остаётся в режиме, вердикта нет, на главную приложение само не уходит.
- [x] Сверху мелко инфинитив, крупно одна причина: «Нет разрешения микрофона», «Модель не открылась» или «Распознавание не стартовало». Снизу только «Ещё раз».
- [x] Если нужная модель не открылась, причина — «Модель не открылась», даже когда разрешения тоже нет.
- [x] Уже прозвучавшая фраза сама не повторяется, если после неё распознавание не стартовало.
- [x] «Ещё раз» при открытой модели и отсутствующем разрешении запрашивает разрешение. Если система больше не показывает запрос, открываются настройки приложения, причина на экране та же.
- [x] Возврат из настроек проверяет способности заново и показывает ту причину, которая есть сейчас. Если помехи нет, причины нет и ход ждёт «Ещё раз», фраза сама не стартует.
- [x] Когда «Ещё раз» проходит, дальше обычный ход того же глагола: озвучка один раз сама, затем слушание.
- [x] Из этого состояния можно выйти на главную и открыть страницу глаголов. Под ней ход стоит. Возврат попытку сам не начинает.
- [x] Обрыв после старта слушания не показывает эти три причины и не убирает «Готово».
- [x] Причины и команды «запросить разрешение» и «открыть настройки» проверяются через ход подставными исходами.
